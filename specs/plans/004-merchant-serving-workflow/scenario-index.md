## 情境 3：店家接單、開始出餐並完成訂單

**業務規則**：三個前進 transition 逐步保存且快照不變

| 誰驗 | 驗什麼 | Feature 位置 |
| --- | --- | --- |
| 前端 | 三個前進 transition 逐步保存且快照不變 | `frontend/店家訂單/訂單看板.feature#店家接受已建立訂單；店家開始準備已接單訂單；店家完成出餐中的訂單` |
| 後端 | 狀態更新依 expected state 條件寫入且不改快照 | `backend/訂單/店家訂單與出餐.feature#created 訂單接受後持久化為 accepted；accepted 訂單開始出餐後持久化為 preparing；preparing 訂單完成後持久化為 completed` |
| 前端 | 顧客 query 反映店家寫入同一持久化狀態 | `frontend/顧客訂單/查詢狀態.feature#顧客看到店家接單後的狀態；顧客看到店家完成出餐後的狀態` |
| 後端 | 顧客與店家讀取同一權威 status | `backend/訂單/店家訂單與出餐.feature#顧客查詢反映店家已更新的狀態` |

**缺口**：無

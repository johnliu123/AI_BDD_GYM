# 後端 / 菜單 DSL

公開菜單讀取（001）與店家菜單維護（006）的持久化／API 契約。仍有餐點引用的分類不得刪除。

## 公開菜單讀取 — Given 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 後端實作語意 |
| --- | --- | --- | --- | --- |
| `菜單資料中有多個分類及其所屬餐點` | 無 | 不支援 | 無 | `權威狀態落地`：建立多個 categories 及關聯 menu_items，含 name、image_url、price、category_id。`Arrange 來源`：供 listCategories／listMenuItems 讀取。 |
| `菜單中有屬於不同分類的餐點` | 無 | 不支援 | 無 | `權威狀態落地`：至少兩個分類各有一筆以上 menu item。 |
| `菜單中沒有任何餐點` | 無 | 不支援 | 無 | `權威狀態落地`：categories 可存在但 menu_items 為空集合。 |
| `菜單中有一項沒有圖片的餐點` | 無 | 不支援 | 無 | `權威狀態落地`：一筆 menu item 的 image_url 為 null，其餘欄位有效。 |
| `菜單中有一項沒有價格的餐點` | 無 | 不支援 | 無 | `權威狀態落地`：一筆 menu item 的 price 為 null，其餘欄位有效。 |
| `菜單中有一項沒有分類的餐點` | 無 | 不支援 | 無 | `權威狀態落地`：一筆 menu item 的 category_id 為 null，其餘欄位有效。 |

## 公開菜單讀取 — When 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 後端實作語意 |
| --- | --- | --- | --- | --- |
| `顧客檢視菜單` | 無 | 不支援 | 無 | `怎麼做`：GET 公開菜單（含 categories 與 menu-items，不帶 category 篩選或等同「全部」）。`回寫`：200 與餐點集合。 |
| `顧客檢視分類 "{分類}" 的菜單` | `分類`：字串；已存在分類名稱。 | 不支援 | 無 | `怎麼做`：GET menu-items 並帶 category_id／分類篩選對應「{分類}」。`回寫`：僅該分類餐點。 |

## 公開菜單讀取 — Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 後端實作語意 |
| --- | --- | --- | --- | --- |
| `每項餐點都包含正確的名稱、圖片、價格與分類` | 無 | 不支援 | 無 | `必查`：`呈現結果`：每筆 item 的 name、image_url、price、category_name（或 category_id）與 DB 一致。 |
| `每項餐點的分類都符合其菜單資料關聯` | 無 | 不支援 | 無 | `必查`：`權威狀態`：category 外鍵與回傳分類欄位一致；`不該發生`：不得錯置其他餐點分類。 |
| `結果只包含分類 "{分類}" 的餐點` | `分類`：字串。 | 不支援 | 無 | `必查`：`呈現結果`：集合內每筆皆屬該分類；其他分類餐點不得出現。 |
| `餐點結果為空集合` | 無 | 不支援 | 無 | `必查`：`呈現結果`：items 為空陣列或零筆。 |
| `分類資料不會被錯誤呈現為餐點` | 無 | 不支援 | 無 | `必查`：`不該發生`：回應不得把 category 列當 menu item；空餐點時仍可有 categories 端點。 |
| `菜單結果仍包含該餐點` | 無 | 不支援 | 無 | `必查`：`呈現結果`：缺欄位餐點仍出現在 list 結果中。 |
| `該餐點沒有圖片內容` | 無 | 不支援 | 無 | `必查`：`呈現結果`：image_url 為 null 或省略；`權威狀態`：與 DB null 一致。 |
| `該餐點沒有價格內容` | 無 | 不支援 | 無 | `必查`：`呈現結果`：price 為 null；不得回傳 0 或假價格。 |
| `該餐點沒有分類內容` | 無 | 不支援 | 無 | `必查`：`呈現結果`：category 欄位為 null；不得映射到其他分類。 |

## 店家菜單維護（006）

## Given 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 後端實作語意 |
| --- | --- | --- | --- | --- |
| `店家憑證具有菜單管理權限` | 無 | 不支援 | 無 | `使用 fixture`：提供 menu 或 admin 角色憑證；`權威狀態`：credentials 設定允許菜單寫入。 |
| `系統已有一個菜單分類` | 無 | 不支援 | 無 | `權威狀態落地`：建立可用 categories row，供 menu item 外鍵引用。 |
| `系統已有一個仍被餐點使用的分類` | 無 | 不支援 | 無 | `權威狀態落地`：建立 category 及至少一筆引用該 category 的 menu item；保存刪除前關聯供不變性驗證。 |
| `系統已有一項餐點` | 無 | 不支援 | 無 | `權威狀態落地`：建立 menu item 並保存其目前規格群組與選項；供店家更新操作使用。 |
| `系統已有一項餐點且存在引用該餐點的既有訂單` | 無 | 不支援 | 無 | `權威狀態落地`：建立 menu item 及建立時 order item name/price snapshots。 |
| `一項供應中的餐點存在於菜單` | 無 | 不支援 | 無 | `權威狀態落地`：建立 is_active=true 的菜單餐點；`Arrange 來源`：公開菜單可讀取該餐點。 |
| `一項停止供應的餐點存在於菜單` | 無 | 不支援 | 無 | `權威狀態落地`：建立 is_active=false 的菜單餐點；`Arrange 來源`：公開菜單可讀取該餐點。 |
| `一項供應中的餐點有多個供應中的規格選項` | 無 | 不支援 | 無 | `權威狀態落地`：建立供應中的餐點及至少兩個 is_active=true 的選項。 |

## When 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 後端實作語意 |
| --- | --- | --- | --- | --- |
| `店家建立一個分類` | 無 | 不支援 | 無 | `怎麼做`：建立 category；`權威狀態落地`：分類保存並符合唯一名稱約束；`回寫`：回傳分類；`不必查`：不刪除或移轉餐點。 |
| `店家嘗試刪除該分類` | 無 | 不支援 | 無 | `怎麼做`：提出一次分類刪除請求；`權威狀態落地`：引用檢查發現仍有餐點時拒絕且不刪除任何資料；`回寫`：回傳 `CATEGORY_IN_USE`；`不必查`：不可自動移轉或 cascade 刪除餐點。 |
| `店家建立一項包含名稱、價格及所屬分類的餐點` | 無 | 不支援 | 無 | `怎麼做`：建立 menu item；`權威狀態落地`：保存名稱、十進位價格、category_id、image_url 及 is_active 預設；`回寫`：menu row；`不必查`：不建立未提供的欄位值。 |
| `店家更新餐點名稱或價格` | 無 | 不支援 | 無 | `怎麼做`：更新 menu item 名稱或價格；`權威狀態落地`：只更新菜單 row；`回寫`：新菜單值；`不必查`：不得更新既有 order_item snapshots。 |
| `店家更新該餐點的規格群組與選項` | 無 | 不支援 | 無 | `怎麼做`：更新一項餐點的 option groups/options；`權威狀態落地`：保存群組名稱、選項名稱、price_adjustment、is_active；`回寫`：更新後餐點資料；`不必查`：不更改其他餐點或既有訂單快照。 |
| `店家將該餐點設為停止供應` | 無 | 不支援 | 無 | `怎麼做`：更新指定餐點供應狀態；`權威狀態落地`：is_active=false；`回寫`：更新結果；`不必查`：不更動其他菜單資料。 |
| `店家恢復該餐點供應` | 無 | 不支援 | 無 | `怎麼做`：更新指定餐點供應狀態；`權威狀態落地`：is_active=true；`回寫`：更新結果；`不必查`：不更動其他菜單資料。 |
| `店家將一個規格選項設為停止供應` | 無 | 不支援 | 無 | `怎麼做`：PATCH 指定 option availability；`權威狀態落地`：僅指定 option is_active=false；`回寫`：更新後菜單；`不必查`：不可停用其他選項或餐點。 |

## Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 後端實作語意 |
| --- | --- | --- | --- | --- |
| `分類持久化且可由店家列表讀取` | 無 | 不支援 | 無 | `必查`：`呈現結果`：create 成功；`權威狀態`：categories row 可讀回。 |
| `系統拒絕刪除仍被使用的分類` | 無 | 不支援 | 無 | `必查`：`呈現結果`：回 409 `CATEGORY_IN_USE`；`權威狀態`：分類與所有 menu item 關聯保持原狀；`不該發生`：不得 cascade、移轉或部分刪除。 |
| `分類與餐點關聯維持不變` | 無 | 不支援 | 無 | `必查`：`權威狀態`：重新讀取 category 與關聯 menu items，確認 ID 與外鍵關係未變。 |
| `餐點持久化且顧客菜單可讀到該餐點` | 無 | 不支援 | 無 | `必查`：`權威狀態`：menu_items row 存在；`再讀確認`：公開菜單讀取包含正確餐點欄位。 |
| `菜單資料更新為新值` | 無 | 不支援 | 無 | `必查`：`權威狀態`：菜單 row 為新名稱或價格；`再讀確認`：公開菜單回傳新值。 |
| `既有訂單快照不受影響` | 無 | 不支援 | 無 | `必查`：`權威狀態`：既有 order_item menu_item_name 與 unit_price/line_total 不變；`再讀確認`：查詢訂單仍為原快照。 |
| `餐點供應狀態持久化為停止供應` | 無 | 不支援 | 無 | `必查`：`權威狀態`：菜單餐點 is_active=false；`再讀確認`：資料來源仍回報停止供應。 |
| `顧客菜單讀取到該餐點為停止供應` | 無 | 不支援 | 無 | `必查`：`呈現結果`：公開菜單回傳停止供應狀態；`權威狀態`：與持久化 is_active=false 一致。 |
| `餐點供應狀態持久化為供應中` | 無 | 不支援 | 無 | `必查`：`權威狀態`：菜單餐點 is_active=true；`再讀確認`：資料來源仍回報供應中。 |
| `顧客菜單讀取到該餐點為供應中` | 無 | 不支援 | 無 | `必查`：`呈現結果`：公開菜單回傳供應中狀態；`權威狀態`：與持久化 is_active=true 一致。 |
| `該規格選項供應狀態持久化為停止供應` | 無 | 不支援 | 無 | `必查`：`權威狀態`：指定 option is_active=false；`再讀確認`：公開菜單回傳停供狀態。 |
| `其他規格選項仍維持供應中` | 無 | 不支援 | 無 | `必查`：`權威狀態`：未被更新的 option rows 仍 is_active=true；`不該發生`：不可連帶停用。 |
| `菜單規格群組與選項持久化更新` | 無 | 不支援 | 無 | `必查`：`權威狀態`：群組、選項名稱、加價及 is_active 欄位已保存；`再讀確認`：重新讀取菜單仍一致。 |
| `顧客菜單讀取到更新後的規格及加價` | 無 | 不支援 | 無 | `必查`：`呈現結果`：公開菜單回傳更新後群組、選項與價格調整；`權威狀態`：內容與持久化菜單資料一致。 |

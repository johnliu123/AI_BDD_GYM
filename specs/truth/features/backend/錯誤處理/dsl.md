# 後端 / 錯誤處理 DSL

## 技術 DSL（測試落地參考）

## Given 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 後端實作語意 |
| --- | --- | --- | --- | --- |
| `建立菜單資料的請求缺少必要欄位` | 無 | 不支援 | 無 | `使用 fixture`：準備缺少必要欄位的請求；`權威狀態`：記錄受影響菜單資料操作前狀態。 |
| `請求指向不存在的操作` | 無 | 不支援 | 無 | `使用 fixture`：準備不匹配任何已分析 API 操作的路徑；`權威狀態`：不建立任何業務資料。 |
| `顧客對不可操作的訂單執行付款或取消` | 無 | 不支援 | 無 | `權威狀態落地`：準備處於不允許該操作之狀態的既有訂單；`不必查`：不預先修改訂單。 |
| `顧客或店家提出不符合業務規則的操作` | 無 | 不支援 | 無 | `使用 fixture`：準備會由已知業務規則拒絕的一次操作；`權威狀態`：保存失敗前的相關資料供不變性檢查。 |
| `系統處理請求時發生未預期錯誤` | 無 | 不支援 | 無 | `使用 fixture`：test-local app route 產生含敏感字串的 synthetic error；`權威狀態`：不掛入 production server 或 OpenAPI。 |

## When 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 後端實作語意 |
| --- | --- | --- | --- | --- |
| `系統處理該請求` | 無 | 不支援 | 無 | `怎麼做`：送出 Given 準備的一次請求；`權威狀態`：拒絕時不允許部分寫入；`回寫`：保存回應；`不必查`：不以第二次請求替代本次錯誤檢查。 |
| `系統依業務規則拒絕該操作` | 無 | 不支援 | 無 | `怎麼做`：執行一次付款或取消請求；`權威狀態`：業務拒絕時訂單不得部分轉換；`回寫`：保存回應；`不必查`：不執行其他訂單操作。 |
| `系統拒絕該操作` | 無 | 不支援 | 無 | `怎麼做`：執行 Given 準備的一次不合法業務操作；`權威狀態`：拒絕不得造成部分寫入；`回寫`：保存錯誤結果。 |
| `系統回覆請求者` | 無 | 不支援 | 無 | `怎麼做`：讓 synthetic error 經正式 Express error middleware 處理一次；`權威狀態`：只寫入 server-side log；`回寫`：保存 500 response；`不必查`：不使用 production test endpoint。 |

## Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 後端實作語意 |
| --- | --- | --- | --- | --- |
| `回應包含穩定錯誤代碼與可理解的中文訊息` | 無 | 不支援 | 無 | `必查`：`呈現結果`：錯誤回應含穩定 code 與中文 message，符合既有 ErrorBody 契約。 |
| `菜單資料沒有部分寫入` | 無 | 不支援 | 無 | `必查`：`權威狀態`：重新讀取菜單資料，確認與失敗請求前一致；`不該發生`：無部分建立或更新。 |
| `回應包含穩定的查無錯誤代碼與中文訊息` | 無 | 不支援 | 無 | `必查`：`呈現結果`：未知 API 操作回傳穩定 not-found code 與中文訊息。 |
| `回應使用一致的錯誤結構` | 無 | 不支援 | 無 | `必查`：`呈現結果`：回應遵循 `{ error: { code, message } }`；不得包含內部錯誤細節。 |
| `回應保留該業務錯誤的穩定代碼` | 無 | 不支援 | 無 | `必查`：`呈現結果`：code 保持此業務拒絕既有契約，不被通用中介層覆寫。 |
| `相關訂單資料沒有部分變更` | 無 | 不支援 | 無 | `必查`：`權威狀態`：重新讀取訂單並確認失敗操作前狀態及明細仍一致。 |
| `回應以通用中文訊息說明操作未完成` | 無 | 不支援 | 無 | `必查`：`呈現結果`：500 `INTERNAL_ERROR` 與通用訊息；`不該發生`：body 不含 stack、SQL 或伺服器路徑。 |
| `回應不包含堆疊、資料庫語句或伺服器路徑` | 無 | 不支援 | 無 | `必查`：檢查完整 response body 不包含 stack、SQL 原文或檔案路徑。 |
| `錯誤細節僅供服務端記錄` | 無 | 不支援 | 無 | `必查`：`呈現結果`：client body 不含內部細節；`權威狀態`：safe logger 收到已遮蔽內容。 |
| `處理可預期錯誤不需呼叫外部服務` | 無 | 不支援 | 無 | `必查`：以遠端呼叫 spy 驗證 expected error handling 無額外外部請求；不設計毫秒門檻。 |

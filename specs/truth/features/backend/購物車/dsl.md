# 後端 / 購物車 DSL

匿名訪客購物車的 HTTP 邊界與 PostgreSQL 權威狀態。金額取目前菜單與規格資料即時計算，不持久化衍生金額。

## Given 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 後端實作語意 |
| --- | --- | --- | --- | --- |
| `菜單中有供應中的餐點 "{餐點}" 及其規格群組` | `餐點`：字串；餐點名稱。 | 不支援 | 無 | `權威狀態落地`：建立供應中 menu_item 及至少兩個有效 option groups/options；`回寫`：讀取時群組歸屬同一餐點；`不必查`：無。 |
| `菜單中有未供應的餐點 "{餐點}"` | `餐點`：字串；餐點名稱。 | 不支援 | 無 | `權威狀態落地`：建立 is_active=false 的餐點；`回寫`：加入前菜單仍可辨識但不可供應；`不必查`：不得建立 cart item。 |
| `菜單中有需要選擇多個規格群組的餐點 "{餐點}"` | `餐點`：字串；餐點名稱。 | 不支援 | 無 | `權威狀態落地`：建立餐點及至少兩個有效規格群組與選項；`回寫`：fixture 提供各群組識別；`不必查`：無。 |
| `目前工作階段購物車有多個可用餐點項目` | 無 | 不支援 | 無 | `權威狀態落地`：在目前 session cart 建立至少兩筆項目及所選規格；`回寫`：讀取可用；`不必查`：不預存衍生金額。 |
| `目前工作階段購物車沒有項目` | 無 | 不支援 | 無 | `權威狀態落地`：目前 session cart 的項目集合為空；`回寫`：讀取同一 session 可驗證空狀態；`不必查`：不要求菜單也沒有餐點。 |
| `目前工作階段購物車有可用餐點項目` | 無 | 不支援 | 無 | `權威狀態落地`：目前 session cart 至少有一筆可用項目；`回寫`：項目關聯菜單餐點及有效選項；`不必查`：無。 |
| `目前工作階段購物車有可用餐點 "{餐點}"` | `餐點`：字串；項目餐點名稱。 | 不支援 | 無 | `權威狀態落地`：目前 session cart 有指定可用項目；`回寫`：保存其穩定項目 ID；`不必查`：無。 |
| `目前工作階段購物車有不可用餐點 "{餐點}" 及其他可用項目` | `餐點`：字串；不可用項目名稱。 | 不支援 | 無 | `權威狀態落地`：建立混合項目後停用指定餐點或其所選規格；`回寫`：指定項目 unavailable，其餘項目 available；`不必查`：不刪除不可用項目。 |
| `目前工作階段購物車有不可用餐點 "{餐點}"` | `餐點`：字串；不可用項目名稱。 | 不支援 | 無 | `權威狀態落地`：建立項目後停用餐點或所選規格；`回寫`：指定項目 unavailable；`不必查`：保留 cart row。 |
| `目前工作階段購物車已有餐點 "{餐點}" 且菜單價格或規格加價已變更` | `餐點`：字串；項目名稱。 | 不支援 | 無 | `權威狀態落地`：建立 cart row 後更新 menu price 或 option price_adjustment；`回寫`：讀取採用新價格；`不必查`：不得保留舊金額快照。 |
| `目前工作階段購物車有一個可用餐點 "{餐點}"` | `餐點`：字串；項目名稱。 | 不支援 | 無 | `權威狀態落地`：目前 session cart 有一筆指定 available 項目；`回寫`：保存 item ID；`不必查`：無。 |
| `第一個訪客工作階段的購物車已有餐點 "{餐點}"` | `餐點`：字串；第一個工作階段項目名稱。 | 不支援 | 無 | `權威狀態落地`：使用第一個有效 session 建立指定 cart item；`回寫`：另一 session 不共享 cart_id；`不必查`：不依賴登入身份。 |
| `第二個顧客持有不同的有效訪客工作階段` | 無 | 不支援 | 無 | `權威狀態落地`：建立第二個 server-signed session；`回寫`：session ID 與第一個不同；`不必查`：不提供跨 session 合併。 |

## When 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 後端實作語意 |
| --- | --- | --- | --- | --- |
| `顧客將餐點 "{餐點}" 及每組各一個所選規格加入購物車` | `餐點`：字串；欲新增餐點名稱。 | 不支援 | 無 | `怎麼做`：以目前 session cookie 與所選規格新增一個 cart item；`權威狀態落地`：交易內驗證供應與每群組恰一選，再寫 item/options；`回寫`：回傳最新 cart 與精確總額；`不必查`：不接受 client 金額。 |
| `顧客漏選至少一個群組的選項並嘗試加入餐點 "{餐點}"` | `餐點`：字串；規格未選完整的餐點。 | 不支援 | 無 | `怎麼做`：提交缺少群組選擇的一次新增操作；`權威狀態落地`：驗證全部 menu_item_option_groups，發現缺選即拒絕；`回寫`：回驗證錯誤；`不必查`：不寫入 cart_item 或選項。 |
| `顧客讀取目前工作階段購物車` | 無 | 不支援 | 無 | `怎麼做`：以目前 session 讀取 cart；`權威狀態落地`：唯讀，依當前菜單重算；`回寫`：回 cart items、availability、金額與 total；`不必查`：不得讀取其他 session。 |
| `顧客將餐點 "{餐點}" 的數量更新為 {數量}` | `餐點`：字串；項目名稱。`數量`：正整數。 | 不支援 | 無 | `怎麼做`：依目前 session 與 cart item ID 更新 quantity；`權威狀態落地`：僅 quantity 為正整數且項目可用時更新；`回寫`：重算項目及總額；`不必查`：不接受價格欄位。 |
| `顧客刪除餐點 "{餐點}"` | `餐點`：字串；欲刪除項目名稱。 | 不支援 | 無 | `怎麼做`：依目前 session 刪除對應 item 及 option rows；`權威狀態落地`：刪除限於本 session cart；`回寫`：回剩餘 cart 及重算總額；`不必查`：不可用 item 仍允許刪除。 |
| `顧客提交含自訂項目金額或總金額的購物車更新` | 無 | 不支援 | 無 | `怎麼做`：以額外金額欄位送出更新；`權威狀態落地`：依 request schema 忽略或拒絕非允許欄位，不將金額寫入；`回寫`：金額仍由服務端計算；`不必查`：不持久化 line_total/cart total。 |
| `第二個不同的訪客工作階段讀取自己的購物車` | 無 | 不支援 | 無 | `怎麼做`：使用第二個 session 讀取 cart；`權威狀態落地`：只解析該 session 的 cart；`回寫`：第二個 session 的結果；`不必查`：不探測或回傳第一個 cart 的內容。 |

## Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 後端實作語意 |
| --- | --- | --- | --- | --- |
| `目前工作階段購物車新增餐點 "{餐點}" 及其規格` | `餐點`：字串；新增項目名稱。 | 不支援 | 無 | `必查`：`呈現結果`：回傳項目及規格；`權威狀態`：新增一筆 cart_item 及所選 options；`再讀確認`：以同 session 讀回仍存在。 |
| `項目金額依目前餐點價格、規格加價及數量計算` | 無 | 不支援 | 無 | `必查`：`呈現結果`：unit_price、line_total 為精確十進位字串；`權威狀態`：由目前 menu_item.price、option.price_adjustment、quantity 計算；`不該發生`：不得採信 client 金額。 |
| `系統拒絕新增該項目` | 無 | 不支援 | 無 | `必查`：`呈現結果`：回業務拒絕；`權威狀態`：新增前後 cart rows 相同；`不該發生`：不得留下部分 cart_item 或選項。 |
| `目前工作階段購物車內容維持不變` | 無 | 不支援 | 無 | `必查`：`權威狀態`：失敗操作前後 item、option、quantity 與 total 一致；`再讀確認`：同 session 讀回仍一致。 |
| `第一個工作階段的購物車內容維持不變` | 無 | 不支援 | 無 | `必查`：`權威狀態`：以第一個 session 重新讀取，原 item、option、quantity 與 total 一致；`不該發生`：第二個 session 的讀取不得改變第一個 cart。 |
| `回傳的購物車不包含餐點 "{餐點}"` | `餐點`：字串；不得外洩的其他 session 項目名稱。 | 不支援 | 無 | `必查`：`呈現結果`：第二個 session 回應不含該餐點；`權威狀態`：只查第二個 session cart；`不該發生`：不得因 item ID 或名稱洩漏第一個 session 資料。 |
| `回傳每項餐點、規格、數量與項目金額` | 無 | 不支援 | 無 | `必查`：`呈現結果`：cart response 含所有項目及衍生金額；`權威狀態`：欄位與目前 menu／options 關聯一致。 |
| `回傳總額等於所有可用項目依目前價格計算後的總和` | 無 | 不支援 | 無 | `必查`：`呈現結果`：cart.total 為十進位字串；`權威狀態`：僅加總 available rows；`不該發生`：不可用項目不貢獻 total。 |
| `購物車項目集合為空` | 無 | 不支援 | 無 | `必查`：`呈現結果`：cart items 為空陣列；`權威狀態`：目前 session 沒有 cart item rows。 |
| `購物車總額為零` | 無 | 不支援 | 無 | `必查`：`呈現結果`：total 為精確零值；`權威狀態`：空 cart 計算結果為零。 |
| `項目金額及總額依目前菜單價格重新計算` | 無 | 不支援 | 無 | `必查`：`呈現結果`：金額欄位回傳新計算值；`權威狀態`：使用最新 menu／option 價格；`不該發生`：不沿用舊快照。 |
| `系統不沿用購物車建立時的舊金額` | 無 | 不支援 | 無 | `必查`：`權威狀態`：重讀以目前菜單與規格價格計價；`不該發生`：不得將加入當下金額視為快照。 |
| `購物車金額只依目前餐點價格、規格加價及數量計算` | 無 | 不支援 | 無 | `必查`：`權威狀態`：total 僅由 DB menu_item.price、menu_item_option.price_adjustment 與 quantity 推導；`不該發生`：不得讀取 client 提交的 amount 作為權威。 |
| `項目金額及購物車總額依目前價格重新計算` | 無 | 不支援 | 無 | `必查`：`權威狀態`：PATCH 成功後重新讀取目前價格並計算 line_total/cart total；`呈現結果`：回應和讀回一致。 |
| `系統不採用顧客端提供的金額` | 無 | 不支援 | 無 | `必查`：`權威狀態`：未保存 client 金額；計價等於服務端目前資料；`不該發生`：不可被自訂 total、line_total 或 unit_price 覆寫。 |
| `持久化項目數量為 {數量}` | `數量`：正整數。 | 不支援 | 無 | `必查`：`權威狀態`：DB quantity 等於指定正整數；`呈現結果`：回應與持久化一致。 |
| `持久化購物車不再包含餐點 "{餐點}"` | `餐點`：字串；刪除項目名稱。 | 不支援 | 無 | `必查`：`權威狀態`：該 session cart 無該項目及選項 rows；`再讀確認`：其他 cart rows 保留。 |
| `總金額依剩餘可用項目重新計算` | 無 | 不支援 | 無 | `必查`：`權威狀態`：總額只包含 remaining available rows；`呈現結果`：回應與重新讀取一致。 |
| `餐點 "{餐點}" 仍列於購物車且標示不可用` | `餐點`：字串；不可用項目名稱。 | 不支援 | 無 | `必查`：`權威狀態`：item row 保留且 availability unavailable；`呈現結果`：回應保留名稱與 unavailable；`不該發生`：不刪除項目。 |
| `不可用項目不回傳單價或項目金額且不計入總額` | 無 | 不支援 | 無 | `必查`：`呈現結果`：unit_price／line_total 省略；`權威狀態`：總額不包含不可用項目。 |
| `系統拒絕更新數量` | 無 | 不支援 | 無 | `必查`：`呈現結果`：回 409 unavailable；`權威狀態`：項目與數量維持不變；`不該發生`：不得部分更新。 |
| `持久化購物車內容與總額維持不變` | 無 | 不支援 | 無 | `必查`：`權威狀態`：失敗操作前後 cart rows/options/quantity/total 一致；`再讀確認`：同 session 重新讀取。 |
| `購物車不再包含餐點 "{餐點}"` | `餐點`：字串。 | 不支援 | 無 | `必查`：`權威狀態`：該 cart item 已刪除；`呈現結果`：回傳集合中不再出現該項目。 |

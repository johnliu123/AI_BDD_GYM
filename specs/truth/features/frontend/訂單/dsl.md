# 前端 / 訂單 DSL

顧客確認購物車、查看建單結果與查詢訂單的 UI 契約；訂單狀態與金額以 server response 為準。

## Given 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `顧客的購物車有多項可用餐點與所選規格` | 無 | 不支援 | 無 | `使用 fixture`：建立目前訪客工作階段 cart 並提供多個可用項目。`權威狀態`：後端 cart 可讀且均 available。 |
| `顧客的購物車沒有任何可用項目` | 無 | 不支援 | 無 | `使用 fixture`：建立空 cart 或只含 unavailable items 的 cart。`權威狀態`：沒有可送單項目。 |
| `顧客在目前訪客工作階段建立了一筆訂單` | 無 | 不支援 | 無 | `使用 fixture`：於目前 browser session 建立訂單並保留 order number。`權威狀態`：訂單屬於該 session。 |
| `第一個訪客工作階段建立了一筆訂單` | 無 | 不支援 | 無 | `使用 fixture`：在第一個 browser context 建立訂單。`權威狀態`：保存第一個 session 與 order 的歸屬。 |
| `訂單建立後菜單價格已變更` | 無 | 不支援 | 無 | `使用 fixture`：建單後更新菜單價格。`權威狀態`：新菜單價格與既有訂單快照不同。 |

## When 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `顧客確認並送出購物車` | 無 | 不支援 | 無 | `頁面操作`：在確認流程提交目前購物車一次。`等待條件`：等候成功或拒絕結果。 |
| `顧客嘗試確認並送出購物車` | 無 | 不支援 | 無 | `頁面操作`：在確認流程提交購物車一次；允許目前為空或不可用。 |
| `第二個顧客以該訂單編號查詢訂單` | 無 | 不支援 | 無 | `頁面操作`：在第二個 browser context 提交第一個 session 的訂單編號。 |

## Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `顧客看到訂單編號、初始狀態與訂單明細` | 無 | 不支援 | 無 | `必查`：`呈現結果`：成功頁顯示 order number、初始狀態、items。`權威狀態`：內容與建立回應一致。 |
| `顧客看到建立當下的訂單總金額` | 無 | 不支援 | 無 | `必查`：`呈現結果`：顯示 total。`權威狀態`：等於伺服器建單快照，不由前端重算。 |
| `顧客看到購物車已清空` | 無 | 不支援 | 無 | `必查`：`呈現結果`：成功後購物車為空。`權威狀態`：重新讀取目前 session cart 為空。 |
| `顧客看到無法建立訂單的提示` | 無 | 不支援 | 無 | `必查`：`呈現結果`：顯示建單遭拒訊息；`權威狀態`：cart 保留。 |
| `顧客不會看到新訂單編號` | 無 | 不支援 | 無 | `必查`：`呈現結果`：拒絕結果沒有 order number；`不該發生`：不得展示未成立訂單。 |
| `購物車內容維持不變` | 無 | 不支援 | 無 | `必查`：`權威狀態`：拒絕前後 cart items／quantities 相同。 |
| `顧客看到訂單狀態、建立時間與訂單明細` | 無 | 不支援 | 無 | `必查`：`呈現結果`：查詢頁顯示狀態、時間及 items；`權威狀態`：與訂單讀取結果一致。 |
| `顧客看到建立當下的金額快照` | 無 | 不支援 | 無 | `必查`：`呈現結果`：總額與項目金額可見；`權威狀態`：與建單時快照一致，不受新菜單價格影響。 |
| `顧客看到統一的查無訂單結果` | 無 | 不支援 | 無 | `必查`：`呈現結果`：使用統一查無提示；`不該發生`：不洩漏訂單存在性。 |
| `顧客無法判斷其他工作階段的訂單是否存在` | 無 | 不支援 | 無 | `必查`：`呈現結果`：跨 session 使用相同查無結果；`不該發生`：不得顯示訂單內容或存在狀態。 |

# 前端 / 菜單 DSL

菜單瀏覽與分類篩選的前端專屬句型。測試須使用可驗證的菜單資料，不以 UI 顯示文字取代其對應資料關聯。


## 業務 DSL（人 Review）

| 句型 | 參數 | 意思 |
| --- | --- | --- |
| `菜單中有以下餐點：` | 無 | 菜單中有以下餐點： 的驗證語意 |
| `菜單中有一項沒有圖片的餐點` | 無 | 菜單中有一項沒有圖片的餐點 的驗證語意 |
| `菜單中有一項沒有價格的餐點` | 無 | 菜單中有一項沒有價格的餐點 的驗證語意 |
| `菜單中有一項沒有分類的餐點` | 無 | 菜單中有一項沒有分類的餐點 的驗證語意 |
| `菜單目前沒有任何餐點` | 無 | 菜單目前沒有任何餐點 的驗證語意 |
| `顧客切換到分類 "{分類}"` | `分類`：字串；菜單中已存在的分類名稱。 | 顧客切換到分類 "{分類}" 的驗證語意 |
| `顧客開啟菜單` | 無 | 顧客開啟菜單 的驗證語意 |
| `菜單只顯示分類 "{分類}" 的餐點` | `分類`：字串；目前選取的分類名稱。 | 菜單只顯示分類 "{分類}" 的餐點 的驗證語意 |
| `每張餐點卡都顯示該餐點的名稱、圖片、價格與分類` | 無 | 每張餐點卡都顯示該餐點的名稱、圖片、…的契約 |
| `該餐點仍顯示在菜單中` | 無 | 該餐點仍顯示在菜單中 的驗證語意 |
| `缺少圖片的餐點顯示佔位圖` | 無 | 缺少圖片的餐點顯示佔位圖 的驗證語意 |
| `缺少價格的餐點顯示明確提示` | 無 | 缺少價格的餐點顯示明確提示 的驗證語意 |
| `缺少分類的餐點顯示明確提示` | 無 | 缺少分類的餐點顯示明確提示 的驗證語意 |
| `顧客看到明確的空菜單狀態` | 無 | 顧客看到明確的空菜單狀態 的驗證語意 |
| `菜單不會顯示不存在的餐點` | 無 | 菜單不會顯示不存在的餐點 的驗證語意 |

## 技術 DSL（測試落地參考）

## Given 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `菜單中有以下餐點：` | 無 | 支援：`分類`（必填，字串）、`餐點`（必填，字串）、`圖片`（必填，字串）、`價格`（必填，十進位字串） | 無 | `使用 fixture`：建立分類與餐點資料並保存圖片路徑。`權威狀態`：後端菜單資料含表格中的分類關聯與價格；圖片可由測試應用載入。`Arrange 來源`：完成資料準備後開啟菜單頁。 |
| `菜單中有一項沒有圖片的餐點` | 無 | 不支援 | 無 | `使用 fixture`：建立一筆有名稱、價格、分類且 image_url 為空的餐點。`權威狀態`：後端讀取仍回傳該餐點及空圖片值。`Arrange 來源`：完成資料準備後開啟菜單頁。 |
| `菜單中有一項沒有價格的餐點` | 無 | 不支援 | 無 | `使用 fixture`：建立一筆 price 為 null 的餐點，其他欄位有效。`權威狀態`：後端菜單仍回傳該餐點與 null price。`Arrange 來源`：完成資料準備後開啟菜單頁。 |
| `菜單中有一項沒有分類的餐點` | 無 | 不支援 | 無 | `使用 fixture`：建立一筆 category_id 為 null 的餐點，其他欄位有效。`權威狀態`：後端菜單仍回傳該餐點與 null category。`Arrange 來源`：完成資料準備後開啟菜單頁。 |
| `菜單目前沒有任何餐點` | 無 | 不支援 | 無 | `使用 fixture`：在隔離測試資料中移除餐點，保留分類資料。`權威狀態`：後端餐點查詢結果為空集合。`Arrange 來源`：完成資料準備後開啟菜單頁。 |

## When 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `顧客切換到分類 "{分類}"` | `分類`：字串；菜單中已存在的分類名稱。 | 不支援 | `初始篩選`：頁面開啟時為「全部」。 | `頁面操作`：選取名稱符合的分類標籤，作為一次分類篩選操作。`等待條件`：等待菜單結果更新。`權威狀態`：不修改後端菜單資料。 |
| `顧客開啟菜單` | 無 | 不支援 | 無 | `頁面操作`：開啟顧客菜單頁並載入菜單結果。`等待條件`：等待餐點卡或空菜單狀態呈現。`權威狀態`：顯示結果對應後端菜單讀取資料。 |

## Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `菜單只顯示分類 "{分類}" 的餐點` | `分類`：字串；目前選取的分類名稱。 | 不支援 | 無 | `必查`：`呈現結果`：所有可見餐點皆屬於指定分類，其他分類餐點不顯示。`權威狀態`：對照已建立的菜單 fixture，確認過濾結果沒有遺漏或錯配。 |
| `每張餐點卡都顯示該餐點的名稱、圖片、價格與分類` | 無 | 不支援 | 無 | `必查`：`呈現結果`：每張可見餐點卡的名稱、圖片、價格、分類均完整。`權威狀態`：逐張與 fixture 餐點資料比對，確認圖片、價格及分類對應同一餐點。`不該發生`：不得以其他餐點的欄位補值。 |
| `該餐點仍顯示在菜單中` | 無 | 不支援 | 無 | `必查`：`呈現結果`：缺圖餐點卡仍可見。`權威狀態`：結果包含該 fixture 餐點。`不該發生`：不得因 image_url 為空而過濾餐點。 |
| `缺少圖片的餐點顯示佔位圖` | 無 | 不支援 | `佔位圖`：使用產品既有缺圖呈現。 | `必查`：`呈現結果`：卡片顯示佔位圖而不是破圖或其他餐點圖片。`權威狀態`：該 fixture 的圖片值為空。 |
| `缺少價格的餐點顯示明確提示` | 無 | 不支援 | 無 | `必查`：`呈現結果`：卡片明確顯示暫無價格，不顯示零或假價格。`權威狀態`：API 價格為 null。 |
| `缺少分類的餐點顯示明確提示` | 無 | 不支援 | 無 | `必查`：`呈現結果`：卡片明確顯示暫無分類。`權威狀態`：API 分類欄位為 null，不映射成其他分類。 |
| `顧客看到明確的空菜單狀態` | 無 | 不支援 | 無 | `必查`：`呈現結果`：頁面顯示空菜單提示。`權威狀態`：後端餐點結果為空。`不該發生`：不得顯示樣本或殘留餐點。 |
| `菜單不會顯示不存在的餐點` | 無 | 不支援 | 無 | `必查`：`呈現結果`：沒有餐點卡。`權威狀態`：測試資料中不存在餐點。`不該發生`：不得渲染 fixture 以外的餐點。 |

# 前端 / 購物車 DSL

匿名顧客選擇菜單餐點、調整購物車與檢視金額的前端契約。畫面只呈現服務端權威資料，不自行決定供應狀態或正式金額。


## 業務 DSL（人 Review）

| 句型 | 參數 | 意思 |
| --- | --- | --- |
| `購物車測試菜單中有以下餐點：` | 無 | 購物車測試菜單中有以下餐點： 的驗證語意 |
| `菜單中有需要選擇多個規格群組的餐點 "{餐點}"` | `餐點`：字串；需要規格選擇的餐點名稱。 | 菜單中有需要選擇多個規格群組的餐點 …的契約 |

| `顧客目前工作階段的購物車沒有項目` | 無 | 顧客目前工作階段的購物車沒有項目 的驗證語意 |
| `顧客選擇餐點 "{餐點}" 的每個規格群組各一個選項並加入購物車` | `餐點`：字串；欲加入的餐點名稱。 | 顧客選擇餐點 "{餐點}" 的每個規…的契約 |
| `顧客嘗試加入餐點 "{餐點}"` | `餐點`：字串；本次嘗試加入的餐點名稱。 | 顧客嘗試加入餐點 "{餐點}" 的驗證語意 |
| `顧客未完成規格選擇就嘗試加入餐點 "{餐點}"` | `餐點`：字串；尚未完成規格選擇的餐點。 | 顧客未完成規格選擇就嘗試加入餐點 "…的契約 |
| `顧客再次加入餐點 "{餐點}" 及相同規格` | `餐點`：字串；已加入過的餐點名稱。 | 顧客再次加入餐點 "{餐點}" 及相…的契約 |
| `顧客將餐點 "{餐點}" 的數量改為 {數量}` | `餐點`：字串；項目餐點名稱。`數量`：正整數。 | 顧客將餐點 "{餐點}" 的數量改為…的契約 |
| `顧客刪除購物車中的餐點 "{餐點}"` | `餐點`：字串；要移除的項目名稱。 | 顧客刪除購物車中的餐點 "{餐點}" 的驗證語意 |
| `顧客檢視購物車` | 無 | 顧客檢視購物車 的驗證語意 |

| `購物車顯示包含規格加價的項目金額` | 無 | 購物車顯示包含規格加價的項目金額 的驗證語意 |
| `購物車包含餐點 "{餐點}" 的單一項目` | `餐點`：字串。 | 購物車包含餐點 "{餐點}" 的單一項目 的驗證語意 |

| `購物車總額維持不變` | 無 | 購物車總額維持不變 的驗證語意 |
| `購物車有兩個分開的 "{餐點}" 項目` | `餐點`：字串。 | 購物車有兩個分開的 "{餐點}" 項目 的驗證語意 |
| `系統不合併兩次加入的數量` | 無 | 系統不合併兩次加入的數量 的驗證語意 |
| `購物車顯示餐點 "{餐點}" 的數量 {數量} 與更新後金額` | `餐點`：字串。`數量`：正整數。 | 購物車顯示餐點 "{餐點}" 的數量…的契約 |

| `項目與購物車總額依目前菜單價格重新計算` | 無 | 畫面項目金額與總額依最新菜單／規格價重算 |
| `購物車將餐點 "{餐點}" 標示為不可用` | `餐點`：字串。 | 購物車將餐點 "{餐點}" 標示為不可用 的驗證語意 |
| `購物車不顯示餐點 "{餐點}" 的金額且不計入總額` | `餐點`：字串。 | 購物車不顯示餐點 "{餐點}" 的金…的契約 |
| `系統拒絕修改且購物車內容維持不變` | 無 | 系統拒絕修改且購物車內容維持不變 的驗證語意 |
| `第二個顧客看不到餐點 "{餐點}"` | `餐點`：字串。 | 第二個顧客看不到餐點 "{餐點}" 的驗證語意 |
| `顧客看到空購物車狀態` | 無 | 顧客看到空購物車狀態 的驗證語意 |

## 技術 DSL（測試落地參考）

## Given 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `購物車測試菜單中有以下餐點：` | 無 | 支援：`餐點`（必填，字串）、`價格`（必填，十進位字串）、`供應狀態`（必填，狀態）、`規格群組`（無群組時空值）、`選項`（無選項時空值）、`加價`（無加價時為 0） | 無 | `使用 fixture`：以受控菜單資料建立餐點與規格。`權威狀態`：後端菜單包含表列資料。`Arrange 來源`：建立資料後開啟菜單頁。 |
| `菜單中有需要選擇多個規格群組的餐點 "{餐點}"` | `餐點`：字串；需要規格選擇的餐點名稱。 | 不支援 | 無 | `使用 fixture`：建立至少兩個需各選一項的規格群組。`權威狀態`：所有群組都有效。 |
| `購物車已有餐點 "{餐點}" 及一組規格選擇` | `餐點`：字串；購物車內餐點名稱。 | 不支援 | 無 | `使用 fixture`：建立一個指定餐點及完整規格選擇。`權威狀態`：購物車項目持久化且可讀。 |
| `購物車有多個可用餐點項目` | 無 | 不支援 | 無 | `使用 fixture`：建立至少兩筆可用購物車項目。`權威狀態`：各項目供應中且金額由後端提供。 |
| `購物車有一個可用餐點 "{餐點}"` | `餐點`：字串；購物車項目名稱。 | 不支援 | 無 | `使用 fixture`：建立一個供應中餐點的購物車項目。`權威狀態`：菜單及購物車項目均可用。 |
| `購物車已有餐點 "{餐點}" 且菜單價格或規格加價已更新` | `餐點`：字串；購物車餐點名稱。 | 不支援 | 無 | `使用 fixture`：建立購物車項目後更新菜單權威價格。`權威狀態`：菜單來源為新價格，購物車仍保有原項目。 |
| `購物車有一項已停止供應的餐點 "{餐點}" 及其他可用項目` | `餐點`：字串；停止供應餐點名稱。 | 不支援 | 無 | `使用 fixture`：先建立混合購物車，再將指定餐點設為停供。`權威狀態`：停供狀態由後端持久化，其他項目仍可用。 |
| `購物車有一項不可用餐點 "{餐點}"` | `餐點`：字串；不可用餐點名稱。 | 不支援 | 無 | `使用 fixture`：建立購物車項目後停用餐點或其所選規格。`權威狀態`：項目被判定 unavailable。 |
| `第一個訪客工作階段的購物車已有餐點 "{餐點}"` | `餐點`：字串；第一個工作階段的項目名稱。 | 不支援 | 無 | `使用 fixture`：使用兩個獨立瀏覽器工作階段。`權威狀態`：第一個 session 的購物車含指定項目。 |
| `顧客目前工作階段的購物車沒有項目` | 無 | 不支援 | 無 | `使用 fixture`：建立或清空目前 session 的購物車。`權威狀態`：購物車項目集合為空。 |

## When 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `顧客選擇餐點 "{餐點}" 的每個規格群組各一個選項並加入購物車` | `餐點`：字串；欲加入的餐點名稱。 | 不支援 | 無 | `頁面操作`：開啟該餐點規格選擇，為每組選一項並確認加入，視為一個 UI 操作。`等待條件`：購物車更新完成。 |
| `顧客嘗試加入餐點 "{餐點}"` | `餐點`：字串；本次嘗試加入的餐點名稱。 | 不支援 | 無 | `頁面操作`：只提交一次加入購物車操作。`等待條件`：等待成功或拒絕結果呈現。 |
| `顧客未完成規格選擇就嘗試加入餐點 "{餐點}"` | `餐點`：字串；尚未完成規格選擇的餐點。 | 不支援 | 無 | `頁面操作`：保留至少一組未選狀態並提交一次加入操作。 |
| `顧客再次加入餐點 "{餐點}" 及相同規格` | `餐點`：字串；已加入過的餐點名稱。 | 不支援 | 無 | `頁面操作`：以相同規格再次加入該餐點一次。 |
| `顧客將餐點 "{餐點}" 的數量改為 {數量}` | `餐點`：字串；項目餐點名稱。`數量`：正整數。 | 不支援 | 無 | `頁面操作`：只修改指定可用項目的數量。`權威狀態`：等待伺服器回寫新項目與總額。 |
| `顧客刪除購物車中的餐點 "{餐點}"` | `餐點`：字串；要移除的項目名稱。 | 不支援 | 無 | `頁面操作`：只刪除指定項目。`權威狀態`：等待購物車更新。 |
| `顧客檢視購物車` | 無 | 不支援 | 無 | `頁面操作`：開啟或重新載入購物車。`等待條件`：等待項目、空狀態及金額呈現。 |
| `第二個顧客檢視自己的購物車` | 無 | 不支援 | 無 | `頁面操作`：在第二個 browser context 開啟購物車。`權威狀態`：資料來自第二個 session。 |

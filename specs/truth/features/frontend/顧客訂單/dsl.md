# 前端 / 顧客訂單 DSL

顧客付款與取消操作的 UI 契約；以目前 server response 顯示付款與出餐兩個正交狀態。

## Given 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `顧客在目前訪客工作階段有一筆未付款訂單` | 無 | 不支援 | 無 | `使用 fixture`：目前 browser session 建立 unpaid 訂單；`權威狀態`：訂單 ownership 與目前 session 一致。 |
| `顧客的一筆訂單付款處理失敗` | 無 | 不支援 | 無 | `使用 fixture`：目前 session 訂單 payment status 為 failed，並有可顯示錯誤摘要。 |
| `顧客在目前訪客工作階段有一筆付款失敗的訂單` | 無 | 不支援 | 無 | `使用 fixture`：以目前 browser session 建立 failed 訂單；`權威狀態`：訂單歸屬該 session 且付款狀態可查。 |
| `顧客在目前訪客工作階段有一筆已取消的訂單` | 無 | 不支援 | 無 | `使用 fixture`：以目前 browser session 建立 cancelled 訂單；`權威狀態`：保留付款狀態與訂單快照。 |
| `顧客已成功付款且系統記錄該次付款` | 無 | 不支援 | 無 | `使用 fixture`：目前 session 訂單 paid，保留同一次付款請求識別。 |
| `顧客有一筆尚未接單且尚未付款的訂單` | 無 | 不支援 | 無 | `使用 fixture`：created/unpaid 訂單屬於目前 session。 |
| `顧客有一筆已付款但尚未接單的訂單` | 無 | 不支援 | 無 | `使用 fixture`：created/paid 訂單屬於目前 session。 |
| `訂單已被店家接單或已進入出餐流程` | 無 | 不支援 | 無 | `使用 fixture`：訂單出餐狀態為 accepted、preparing 或 completed。 |
| `訂單尚未接單且付款狀態為「處理中」` | 無 | 不支援 | 無 | `使用 fixture`：created/pending 訂單並提供未 stale 時間狀態。 |
| `訂單尚未接單且付款處理已逾等待時間` | 無 | 不支援 | 無 | `使用 fixture`：建立 created/pending 訂單並將 pending 開始時間設在 stale 門檻之前。`權威狀態`：取消前仍 pending 且已 stale。 |
| `顧客在目前工作階段建立一筆訂單且店家已接單` | 無 | 不支援 | 無 | `使用 fixture`：目前 session 建單後由店家 accept，status=accepted。 |
| `顧客在目前工作階段建立一筆已完成的訂單` | 無 | 不支援 | 無 | `使用 fixture`：目前 session 訂單 status=completed。 |

## When 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `顧客對該訂單發起付款並成功完成` | 無 | 不支援 | 無 | `頁面操作`：按下付款並採用成功結果；`等待條件`：等待付款結果。 |
| `顧客提交的付款資料含有不同的訂單金額` | 無 | 不支援 | 無 | `頁面操作`：僅用測試介面模擬不一致的付款金額輸入；不在使用者 UI 暴露原始 API 操作。 |
| `顧客再次對同一訂單發起新的付款` | 無 | 不支援 | 無 | `頁面操作`：對同一訂單再按付款一次。 |
| `顧客在同一訪客工作階段重新發起付款並成功完成` | 無 | 不支援 | 無 | `頁面操作`：使用目前 session 再次付款並選擇成功結果。 |
| `顧客重送同一付款請求` | 無 | 不支援 | 無 | `頁面操作`：以同一付款請求識別重試一次。 |
| `顧客取消該訂單` | 無 | 不支援 | 無 | `頁面操作`：在訂單頁按取消並確認一次。 |
| `顧客嘗試取消該訂單` | 無 | 不支援 | 無 | `頁面操作`：在不允許狀態嘗試取消一次。 |

## Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `訂單付款狀態更新為「{狀態}」` | `狀態`：字串；顯示用付款狀態。 | 不支援 | 無 | `必查`：`呈現結果`：payment label 更新；`權威狀態`：與 order response 的 payment_status 一致。 |
| `已付金額等於訂單建立時保存的總金額` | 無 | 不支援 | 無 | `必查`：`呈現結果`及`權威狀態`：付金額等於 total 快照，不受提交值影響。 |
| `顧客查詢訂單時看到已付款狀態與原有出餐狀態` | 無 | 不支援 | 無 | `必查`：`呈現結果`：付款／出餐狀態分開呈現；`權威狀態`：與查詢 response 一致。 |
| `顧客看到付款失敗狀態及其對應中文標籤` | 無 | 不支援 | 無 | `必查`：`呈現結果`：顯示 failed 狀態與中文標籤；`權威狀態`：對照訂單查詢 response。 |
| `顧客看到已取消的出餐狀態及付款狀態標籤` | 無 | 不支援 | 無 | `必查`：`呈現結果`：分別顯示 cancelled 與付款狀態標籤；`權威狀態`：對照同一筆訂單 response。 |
| `顧客看到訂單明細與建立時金額快照` | 無 | 不支援 | 無 | `必查`：`呈現結果`：明細與金額可見；`權威狀態`：與建立時 snapshot 一致。 |
| `訂單明細及金額快照維持不變` | 無 | 不支援 | 無 | `必查`：`權威狀態`：order items 與 total 與付款前相同。 |
| `系統仍以訂單建立時保存的總金額作為應付金額` | 無 | 不支援 | 無 | `必查`：`權威狀態`：支付金額取 server snapshot；`不該發生`：不採信客戶端提交值。 |
| `訂單金額快照不會被付款資料覆寫` | 無 | 不支援 | 無 | `必查`：重新查詢訂單 total／items 與付款前完全一致。 |
| `系統不會產生第二次扣款` | 無 | 不支援 | 無 | `必查`：stub／付款結果只有一次成功；`權威狀態`：無第二個成功結果。 |
| `付款狀態維持原狀` | 無 | 不支援 | 無 | `必查`：`權威狀態`：支付狀態與金額操作前後一致。 |
| `先前的失敗結果仍可供查詢` | 無 | 不支援 | 無 | `必查`：`權威狀態`：失敗摘要或時間仍保存；成功結果不覆寫歷史失敗紀錄。 |
| `不會重複扣款或重複變更付款狀態` | 無 | 不支援 | 無 | `必查`：冪等重送回相同結果，付款狀態轉換只有一次。 |
| `顧客看到原付款結果` | 無 | 不支援 | 無 | `必查`：`呈現結果`與首次成功付款的訂單／付款結果相同；`權威狀態`：不新增付款狀態轉換或第二次成功結果。 |
| `訂單出餐狀態更新為「已取消」` | 無 | 不支援 | 無 | `必查`：出餐 status label 顯示 cancelled；`權威狀態`：與 order response 一致。 |
| `付款狀態維持未付款` | 無 | 不支援 | 無 | `必查`：payment status 仍 unpaid。 |
| `訂單明細與金額快照仍可查詢` | 無 | 不支援 | 無 | `必查`：取消後 items／total 仍可查且與建單快照一致。 |
| `後續付款及店家出餐操作都被拒絕` | 無 | 不支援 | 無 | `必查`：付款及店家操作呈現拒絕；取消後狀態不回復。 |
| `付款狀態更新為「已退款」` | 無 | 不支援 | 無 | `必查`：payment label refunded 且可查 refunded_at。 |
| `系統拒絕取消` | 無 | 不支援 | 無 | `必查`：錯誤訊息可見，取消沒有成功呈現。 |
| `出餐狀態與付款狀態維持不變` | 無 | 不支援 | 無 | `必查`：兩個狀態及快照操作前後一致。 |
| `系統拒絕取消並維持訂單狀態` | 無 | 不支援 | 無 | `必查`：非 stale pending 取消遭拒，status/payment_status 仍 pending/created。 |
| `系統先結束未完成的付款處理再將訂單標記為已取消` | 無 | 不支援 | 無 | `必查`：依回應呈現取消成功；`權威狀態`：付款已不再 pending 且出餐狀態 cancelled。 |
| `訂單不會同時處於付款處理中與已取消` | 無 | 不支援 | 無 | `必查`：重讀 order，payment_status != pending 或 status != cancelled。 |
| `顧客看到狀態「已接單」` | 無 | 不支援 | 無 | `必查`：查詢頁出餐狀態 label 為已接單。 |
| `訂單明細與金額快照維持建立時內容` | 無 | 不支援 | 無 | `必查`：items 與 total 仍為建單 snapshot。 |
| `顧客看到狀態「已完成」` | 無 | 不支援 | 無 | `必查`：查詢頁顯示已完成狀態。 |
| `顯示狀態與店家持久化狀態一致` | 無 | 不支援 | 無 | `必查`：UI 狀態與 API／店家看板一致。 |

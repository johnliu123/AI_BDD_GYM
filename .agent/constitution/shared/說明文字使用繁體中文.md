# Shared: 說明文字使用繁體中文

applies_to: all artifacts in CONSTITUTION.md Artifacts table

## MUST

- 面向人類閱讀的敘述、章節標題、表格欄位標題、列表說明使用**繁體中文**。
- 需求 ID、HTTP path、檔名、程式路徑、`operationId`、錨點前綴（如 `spec:`、`openapi:`）維持 template／skill 規定的原文，不強制中文化。

## MUST NOT

- 在受管產物中混用簡體中文作為正式說明（引用第三方原文除外，須標示為引用）。

## 交付自檢（Agent）

- [ ] 掃描標題與表格說明欄，確認無簡體混用
- [ ] 技術識別符未被誤譯成中文
